# 요청사항 반영 결과 (2026-06 작업분, 도급사 공유용)

주신 요청 10건 중 **9건 반영 완료**, 1건(정기청소)은 규모가 커서 별도로 설계 진행 예정입니다.
추가로 **문자 발송(SOLAPI) 가동**과 **모든 안내 발송을 미리보기-확인 방식으로 통일**하는 작업도 함께 했습니다.

---

## ✅ 반영 완료

### 1. 증빙자료(현금영수증/세금계산서) 확인 — ★ 최우선
- **주문 리스트**에 '증빙' 칸 추가 → 한눈에 발급 상태 확인(예: `세금계산서·발급완료`(녹색), `미발급`(주황), `발급X/미설정`(회색)).
- **주문 상세 → 결제/정산**에서 2단계 선택: ①현금영수증 / 세금계산서 / 발급X → ②발급완료 / 미발급. **'발급X' 고르면 2차는 자동 비활성**.

### 2. 결제상태 · 일정 일괄변경
- 주문 여러 건 선택 → **결제상태**(완납/미수 등)와 **방문일**을 한 번에 변경. (기존 상태/협력사 일괄변경과 동일 위치)

### 3. 주문 주소 검색 — 상세주소 포함
- 주소 검색이 기본주소만 찾던 문제 수정 → **상세주소(동/호수 등)로도 검색**됩니다.

### 4. 협력사 담당자 연락처 추가
- 협력사 정보에 '대표 연락처' 외 **'담당자 연락처'** 추가.
- 정산/고객정보 안내는 **담당자 연락처로 우선 발송**(없으면 대표 연락처).

### 5. 협력사 배정작업/정산 — 전체선택 체크박스
- 정산 리스트 헤더에 **전체선택 체크박스** 추가(정산 가능한 건만 선택되도록 처리).

### 6. 미정산/미지급 표시 이슈 수정
- 완료 전 단계라도 **'미지급'으로 표시한 건은 미정산 목록/합계에 표시**되도록 수정(기존엔 '서비스완료' 건만 잡혀서 약 2,400만원 규모가 누락되고 있었음).
- 주문 상세에서 협력사 정산 상태가 비어있을 때 `-` 대신 **'미정산'**으로 표시.

### 7. 주문 복제
- 주문 상세에 **[복제]** 버튼 → **고객정보(이름/연락처/주소)만 복사**한 새 주문 폼이 열림. 서비스/일정/협력사/금액은 새로 입력(여러 서비스 주문 시 재입력 최소화).

### 8. 상품/일정 상세 — 단락 줄바꿈 보존
- 입력 시 넣은 **줄바꿈/단락이 그대로 보이도록** 수정(관리자/협력사/고객 화면 공통).

## 📨 추가 작업 — 문자 발송 가동 & 발송 방식 통일

### 문자(SMS) 발송 가동 (SOLAPI 연동)
- 실제 문자 발송 연동 완료(테스트 발송 정상). **알림톡**은 카카오 템플릿 승인 후 추가 예정(승인 전에는 문자로 발송/대체).

### 모든 안내 발송을 '미리보기 → 확인 후 발송'으로 통일
- 예전엔 일부가 **자동/즉시 발송**(예: 상태 변경 시 잔금 안내 자동 발송, 견적·협력사 고객정보는 버튼 누르면 바로 발송)이었으나,
- **이제 7종 모두 버튼 → 미리보기 → 확인 후에만 발송**됩니다(실수 발송 방지).
- 어떤 상황에서 어떤 문구가 나가는지 + 문구 수정 요청 양식: **별도 문서 `message-triggers-and-wording.md`** 참고.
