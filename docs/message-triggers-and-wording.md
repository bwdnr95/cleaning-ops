# 메시지 발송 정리 (도급사 검토용) — 언제 · 어떤 상태 · 어떤 문구

- 갱신일: 2026-06-19
- 목적: 어떤 상황에서 어떤 문자/알림톡이 고객·협력사에게 나가는지 한눈에 보고, **문구 수정 요청**을 받기 위함.
- 현재 채널: SMS 가동(SOLAPI). 알림톡은 템플릿 승인 후 추가 예정(승인 전엔 SMS로 발송/폴백).

---

## 1. 발송 메시지 한눈에

| # | 메시지 | 받는 사람 | 언제 나가나(트리거) | 발송 방식 | 부가 효과 |
|---|--------|-----------|----------------------|-----------|-----------|
| 1 | 일정확정 안내 | 고객 | 주문상세 **[일정확정 안내]** 버튼 | 미리보기 → 확인 발송 | 발송 성공 시 상태 → **일정확정** |
| 2 | 전날 안내 | 고객 | 주문상세 **[전날 안내]** 버튼 | 미리보기 → 확인 발송 | 발송 성공 시 상태 → **전날안내완료** |
| 3 | 협력사 배정 안내 | 협력사 | 주문상세 **[협력사 배정 안내]** 버튼 (협력사 배정된 주문만) | 미리보기 → 확인 발송 | 발송 성공 시 상태 → **협력사확인중** |
| 4 | 사진 링크 발송 | 고객 | 주문상세 **[사진 링크 발송]** 또는 사진검수 화면 버튼 (공개 사진 1장 이상) | 미리보기 → 확인 발송 | 상태 변경 없음(재발송 가능) |
| 5 | 잔금 안내 | 고객 | 주문상세 **[잔금 안내]** 버튼 | 미리보기 → 확인 발송 | 상태 변경 없음 |
| 6 | 견적 안내 | 고객 | 주문 저장 후 주문상세 **[견적 안내]** 버튼 | 미리보기 → 확인 발송 | 견적서엔 도급가 미포함 |
| 7 | 협력사 고객정보(미입금) | 협력사 | 협력사관리 정산탭 **[고객정보 전송]** → 모달 | 미리보기 → 확인 발송 | 협력사 담당자 연락처 우선 |

> **모든 발송은 '버튼 → 미리보기 → 확인' 후에만 나갑니다. 자동 발송 없음.** (2026-06-19 변경)
> 예전엔 상태를 '고객전달필요'로 바꾸면 잔금 안내가 자동 발송, 견적·협력사 고객정보는 버튼 누르면 즉시 발송이었으나 — 모두 미리보기-확인 방식으로 통일했습니다.

## 2. 실제 문구 (수정 검토 대상)

`[클린잡]`로 시작하며, `{ }`는 주문 데이터로 자동 치환됩니다. 링크는 `https://cleanjob.tono-operation.com/c/<고객별 코드>` 형태입니다.

**1) 일정확정 안내**
```
[클린잡] {고객명}님, 예약 일정이 확정되었습니다.
서비스: {서비스명}
방문: {방문일정}
주소: {주소}
예약 확인: {고객링크}
```

**2) 전날 안내**
```
[클린잡] 내일 방문 예정 안내드립니다.
서비스: {서비스명}
방문: {방문일정}
요청사항과 안내는 아래 링크에서 확인해주세요.
{고객링크}
```

**3) 협력사 배정 안내**
```
[클린잡] {협력사명}에 신규 작업이 배정되었습니다.
방문: {방문일정}
서비스: {서비스명}
고객: {고객명}
주소: {주소}
요청사항: {요청사항 또는 -}
```

**4) 사진 링크 발송**
```
[클린잡] {고객명}님, {서비스명} 작업 사진 확인이 준비되었습니다.
아래 링크에서 연락처 뒷자리 인증 후 확인해주세요.
{고객링크}
```

**5) 잔금 안내**
```
[클린잡] {고객명}님, {서비스명} 작업이 완료되었습니다.
잔금: {잔금}
결제 및 작업 내역 확인: {고객링크}
```

**6) 견적 안내**
```
[클린잡] {고객명}님 견적 안내드립니다.
서비스: {서비스명}
소비자가(VAT {포함/별도}): {금액}
할인가: {할인가}
계약금: {계약금} / 잔금: {잔금}
방문: {방문일정}
```

**7) 협력사 고객정보(미입금)**
```
[클린잡] {담당자/협력사명}님, 미입금 고객 정보를 전달드립니다.
고객: {고객명} ({연락처 뒷4자리 마스킹})
방문: {주소}
요청사항: {요청사항 또는 -}
```

## 4. 참고 (개발 메모)
- 문구 원본: `backend/app/services/messages.py` → `_render_content()`.
- 발송 방식 분류 근거: 미리보기-확인은 `OrderDetailPage` 미리보기 모달 경유, 6·7은 버튼 즉시 발송.
- 알림톡 전환 시: 같은 메시지를 카카오 알림톡 템플릿으로 보냄(승인된 템플릿 변수는 `domain/message_templates.py` 기준). 알림톡 실패 시 SMS 자동 폴백.
